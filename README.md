# 🎙 LiveAnnouncer
### Created by RB and Claude AI

Accessibility-first TikTok Live announcer. Built for streamers with visual impairments.

## Deploy to Railway / Render
- Build command: `npm install`
- Start command: `node server.js`

## Features
- Full charcoal + amber UI, full width
- Diamond Glow members with live status
- 40+ built-in sounds, per-gift sound assignment
- ElevenLabs + PlayHT + browser voice support
- Auto-translate non-English comments
- Voice commands with confirmation flow (say "LiveAnnouncer")
- Auto-learns new TikTok gifts during streams
- Session ID guided setup
